# dartsnut-widget-tools (deprecated)

This repository is deprecated and holds no code. Use these instead:

- [feocco/pixeldarts-chess](https://github.com/feocco/pixeldarts-chess) for
  the PixelDarts Chess game, the Stockfish evaluator, chess tests, and design
  docs.
- [feocco/dartsnut-board](https://github.com/feocco/dartsnut-board) for the
  `tools/dartsnut` upload CLI, the Codex Status widget, board docs, and Cursor
  Cloud setup scripts.

Full history is preserved in this repository's git log. The last commit with
code is `daa47b4`. The pre-split history through `43261ce`, including the
opening-selection scene, is also mirrored in the pixeldarts-chess branch
[`archive/widget-tools-43261ce`](https://github.com/feocco/pixeldarts-chess/tree/archive/widget-tools-43261ce).

`.cursor/environment.json` stays only because the Cursor Cloud environment
`dartsnut-project` still lists this repository. It delegates to
`../dartsnut-board/.cursor/cloud/install.sh`.
