# Status frame

## Sub-features

Border, title, board label, clock, and upload label.

## How to get to it (user POV)

Open `widgets/codex_status_128_128` in Dartsnut Agent.

## Driving it with Dartsnut Agent

Reload the app and capture the first complete frame.

## Gotchas

The widget uses the local system clock, so exact pixels change each second.
