# Board upload

## Sub-features

Manifest file selection and preserved page settings.

## How to get to it (user POV)

Run the upload plan, then the upload command.

## Driving it with Dartsnut Agent

Use `verify-upload-cli` for protocol behavior. Reload this widget in Dartsnut
Agent for rendered behavior.

## Gotchas

Do not use a real board before reviewing the plan.
